# Writing the Instagram caption (out/post.md)

Reach is decided by the video (watch time, likes per reach, sends per reach; sends count slightly more for
non-followers). The caption's jobs are search (Instagram search and Google, both read it) and carrying one ask. A bad caption can cost reach (a hashtag pile,
gated content, an essay); a good one keeps pulling search traffic after day one.

## Rules, in order

1. **Line 1 is the plain search phrase the viewer would type** ("App Store screenshots", "meal prep for one", "paywall design"), within the first ~40 characters, plus
   the payoff. Never the video's hook verbatim: "from this into this" means nothing as text.
2. **A numbered recap of the steps** (3-7 lines, instructions, one concrete example where it helps). It is what
   gets saved and sent, and it puts every sub-keyword in indexable text. Keep the video's own wording.
3. **One ask.** Default: a send ask that names a recipient ("Send this to a friend shipping an app this
   month"): sends per reach is the stated lever for non-followers. A comment-keyword DM only when a real
   resource exists and the automation is live: a distinctive keyword, new per reel, and the reel stays fully
   useful without commenting (gating content is against Meta policy).
4. **Never bare engagement bait** ("like if", "comment YES", "tag someone"): Instagram removes it from recommendations.
5. **3-5 specific hashtags at the end**, in the caption (hard cap 5 since Dec 2025; they label the topic, they
   don't add reach).
6. **30-90 words, under ~500 characters** including hashtags. `wc` it.
7. **The same keyword in the video**: said in the first two seconds and shown as on-screen title text, outside
   the top and bottom ~250 px. That is a script and plan choice, not a caption one; flag it if the cut lacks it.
8. Write it in the user's voice: match how they talk in the take, plain, second person, no hype words. No emoji bullets.

## Template

```
[SEARCH PHRASE]: [payoff], [format cue, e.g. before → after]

1. [step]
2. [step]
3. [step]

[ONE ask]

#[tag] #[tag] #[tag] #[tag] #[tag]
```

In post.md, give the reach version first and, only if a resource exists, the lead version (the ask line swapped).
